# Maquis Patrol Tracker

An unofficial, fan-made Android companion app to track the 10 Patrol cards for the solo board game **Maquis**, in **English** and **French**.

*(Version française ci-dessous)*

## Features

* **Bilingual**: English & French patrol card locations, sorted alphabetically.

* **One-tap tracking**: Tap a card to turn it off when drawn.

* **Live counter & Reset**: Displays active patrols (`10 / 10`) with a one-tap **Reset All** button.

* **Two themes**: Boardgame theme and a modern dark theme. Language and theme choices are saved automatically.

## Installation

1. Download the latest `.apk` from the releases.

2. Open the file on your Android phone and allow installation from unknown sources if prompted.

## Fonctionnalités (FR)

Application Android non officielle pour suivre les 10 cartes Patrouille du jeu de société solo **Maquis**, en **français** et en **anglais**.

* **Bilingue** : noms français et anglais des lieux, triés par ordre alphabétique.

* **Suivi en un clic** : touchez une carte pour l'éteindre ou la rallumer.

* **Compteur et réinitialisation** : affiche les patrouilles actives (`10 / 10`) avec un bouton **Réinitialiser**.

* **Deux thèmes** : Style inspiré du jeu et thème sombre moderne. La langue et le thème sont sauvegardés automatiquement.

## Installation (FR)

1. Téléchargez le dernier fichier `.apk` dans la section releases.

2. Ouvrez le fichier sur votre téléphone Android et autorisez l'installation si demandé.
